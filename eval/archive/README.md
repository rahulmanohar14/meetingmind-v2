# eval/archive

Not loaded by any script. Kept for reference only.

`multi_hop.json` — the five multi-hop questions from the routing version of this
system, where they were used to compare vector retrieval against the knowledge
graph. Neither store won (vector answered 3/5, graph 2/5), the graph was
removed, and these questions left the golden set with it. They are written
against the original four transcripts, so their `answer_turn_ids` only resolve
against that corpus.
